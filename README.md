## 📖 Proje Hakkında

Bu proje, **MY Academy** eğitimi kapsamında geliştirilmiş, **ASP.NET Core MVC** tabanlı bir **kişisel portfolyo uygulamasıdır.**

Uygulama iki ana parçadan oluşur:

1. **Ziyaretçi Tarafı (Public Site):** Tek sayfalık (single-page) bir portfolyo. Hero, Hakkımda, Yetenekler, Deneyim, Projeler, Eğitim ve İletişim bölümlerinin tamamı veritabanından beslenir.
2. **Yönetim Paneli (`/Admin` Area):** Sitedeki tüm içeriğin eklenebildiği, güncellenebildiği ve silinebildiği, ayrıca gelen ziyaretçi mesajlarının takip edildiği panel.

Site içeriği koda gömülü değildir; yönetim panelinden yapılan her değişiklik doğrudan yayındaki siteye yansır.

## ✨ Özellikler

### 🌐 Ziyaretçi Tarafı
- Responsive, modern ve tek sayfalık portfolyo tasarımı
- Bölüm bazlı **View Component** mimarisi (Header, Navbar, Hero, About, Skills, Experience, Projects, Education, Contact, Social Links…)
- **Hero** bölümü, **Hakkımda** bölümü (istatistik kartları, CV bağlantısı dahil)
- **Yetenekler:** Kategori başlıkları ve altlarındaki yetenek maddeleri
- **Deneyim** ve **Eğitim** zaman çizgisi (sıralama ve aktif/pasif desteği)
- **Öne çıkan projeler:** Yalnızca aktif projeler, en yeniden eskiye sıralı; kategori, teknoloji etiketleri ve GitHub bağlantısıyla birlikte
- **İletişim formu:** Sunucu taraflı doğrulama, `AntiForgeryToken` koruması ve kullanıcıya başarı/hata bildirimi (`TempData`)
- Sosyal medya bağlantıları (veritabanından yönetilir)

### 🔧 Yönetim Paneli (Admin Area)
- 📊 **Dashboard:** Toplam/aktif proje sayısı, yetenek, deneyim, eğitim sayıları, toplam ve **okunmamış mesaj** sayısı, son 5 mesaj, son 3 proje ve kategori bazlı özet
- 🗂️ **Proje yönetimi:** CRUD, kategori seçimi, aktif/pasif durumu, **görsel yükleme** (jpg, jpeg, png, webp – maks. 5 MB, benzersiz GUID dosya adı) ve güncellemede eski görselin otomatik silinmesi
- 🏷️ **Kategori** ve **Proje Teknolojileri** yönetimi
- 🧠 **Yetenek** ve **Yetenek Öğeleri** yönetimi
- 💼 **Deneyim** ve 🎓 **Eğitim** yönetimi
- 👤 **Hakkımda**, 📞 **İletişim** ve 🔗 **Sosyal Medya** yönetimi
- ✉️ **Mesaj kutusu:** Ziyaretçilerden gelen mesajları listeleme ve okundu/okunmadı takibi
- Modüler admin arayüzü (Head, Navbar, Sidebar, Style, Script bileşenleri **ViewComponent** olarak ayrılmıştır)
- Türkçe hata mesajlı **Data Annotations** ile model doğrulama

```
MYAcademy_PortfolioProject/
├── Areas/
│   └── Admin/
│       ├── Controllers/        # Admin CRUD controller'ları (Project, Skill, Message, …)
│       ├── Models/             # DashboardViewModel
│       ├── ViewComponents/     # Admin layout bileşenleri (Head, Navbar, Sidebar, …)
│       └── Views/              # Admin Razor görünümleri
├── Context/
│   └── PortfolioContext.cs     # EF Core DbContext
├── Controllers/
│   ├── DefaultController.cs    # Ana sayfa + mesaj gönderme (POST)
│   ├── HomeController.cs
│   └── ExperienceController.cs
├── Entities/                   # Veri modelleri (About, Project, Skill, Message, …)
├── Migrations/                 # EF Core migration dosyaları
├── ViewComponents/
│   └── DefaultViewComponents/  # Ziyaretçi sitesinin bölüm bileşenleri
├── Views/                      # Razor görünümleri ve ViewComponent şablonları
├── wwwroot/                    # Statik dosyalar (css, js, images, lib)
└── Program.cs                  # Uygulama giriş noktası ve routing
```

### 🗃️ Veri Modeli

| Varlık | Açıklama |
|---|---|
| `About` | Ad-soyad, unvan, açıklama, profil görseli, konum, meslek, 3 istatistik kartı, CV bağlantısı |
| `HeroSection` / `HeroTitle` | Karşılama metni, başlık, açıklama, ana görsel ve sıralı/aktif başlıklar |
| `Skill` → `SkillItem` | Yetenek kategorisi (1) → yetenek maddeleri (N) |
| `Experience` | Deneyim başlığı, şirket, açıklama, kategori, aktiflik |
| `Education` | Derece, bölüm, kurum, açıklama, rozet metni, sıralama, aktiflik |
| `Category` → `Project` | Proje kategorisi (1) → projeler (N) |
| `Project` → `ProjectTechnology` | Proje (1) → kullanılan teknolojiler (N) |
| `Message` | Gönderen adı, e-posta, konu, mesaj, tarih, okundu bilgisi |
| `Contact` | Başlık, açıklama, e-posta, konum, telefon |
| `SocialMedia` | Platform adı, ikon, bağlantı |

**İlişkiler:** `Category 1—N Project`, `Project 1—N ProjectTechnology`, `Skill 1—N SkillItem`

## ⚙️ Kurulum ve Çalıştırma

### Gereksinimler
- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)
- SQL Server veya **SQL Server Express**
- Visual Studio 2022+ (önerilir) ya da herhangi bir .NET uyumlu IDE

### Adımlar

**1. Repoyu klonlayın**
```bash
git clone https://github.com/yavuzsevimdev/PortfolioProject.git
cd PortfolioProject/MYAcademy_PortfolioProject
```

**2. Veritabanı bağlantısını kontrol edin**

Bağlantı dizesi `Context/PortfolioContext.cs` içinde tanımlıdır. Kendi SQL Server bilgilerinize göre düzenleyin:

```csharp
optionsBuilder.UseSqlServer(
    "Server=localhost\\SQLEXPRESS;Database=PortfolioDb; integrated security=true; Trust Server Certificate=true");
```

**3. Migration'ları uygulayarak veritabanını oluşturun**
```bash
dotnet ef database update
```
> `dotnet-ef` yüklü değilse: `dotnet tool install --global dotnet-ef`
> Visual Studio'da: *Package Manager Console* → `Update-Database`

**4. Uygulamayı çalıştırın**
```bash
dotnet run
```

| Adres | Açıklama |
|---|---|
| `https://localhost:7047` | Ziyaretçi sitesi |
| `http://localhost:5279` | Ziyaretçi sitesi (HTTP) |
| `https://localhost:7047/Admin/Dashboard/Index` | Yönetim paneli |

**5. İçerik ekleyin**

İlk açılışta veritabanı boştur. Admin panelinden *Hakkımda, Yetenekler, Deneyimler, Projeler, Eğitim, İletişim ve Sosyal Medya* bilgilerini ekleyerek siteyi doldurabilirsiniz.

## 🔐 Güvenlik Notları

- Form işlemlerinde `[ValidateAntiForgeryToken]` kullanılır (CSRF koruması).
- Görsel yüklemede **uzantı beyaz listesi** ve **5 MB boyut sınırı** uygulanır; dosyalar GUID ile yeniden adlandırılır.
- Modeller `Data Annotations` ile sunucu tarafında doğrulanır.
